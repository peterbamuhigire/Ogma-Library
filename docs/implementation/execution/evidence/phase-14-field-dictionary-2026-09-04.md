# Phase 14 metadata field dictionary evidence

Date: 2026-09-04

`MetadataFieldPolicy.KnownFields` is now the shared ordered dictionary for
provider metadata, review proposals, catalogue fields, and PDF write-back. It
covers title, author, identifiers, edition metadata, ratings, language, and
write-back subject/keyword fields. Work-scoped fields and edition-scoped fields
are classified explicitly and tested case-insensitively.

The remaining Phase 14 gates are bulk preview/undo and keyboard/screen-reader
UI journeys, plus their external accessibility evidence.
