# Phase 00 — Icon Manifest

interactive controls. There are no new icons in this phase.

The icon system is **specified** in `docs/plans/grand-plan/ICON-SYSTEM.md` and
**instantiated** (with the first procurement request to the owner) in Phase 03.

No owner icon-procurement request is raised by this phase.
