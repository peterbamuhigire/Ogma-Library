# Phase 14 — Icon Manifest

Icons for the 3D Bookshelf surface. Category path:
`OgmaLibrary.App/Assets/icons/shelf3d/`.

**Special note on spine textures:** Spine textures are NOT icons in the
`IconCatalog` sense — they are SkiaSharp-generated PNG files cached in the
sidecar `spines/` folder and served via `ogma://`. They are not procured from
the premium icon vendor. See README §7.5 for the generation specification.
