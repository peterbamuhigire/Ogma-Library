# Phase 01 — Icon Manifest

Phase 01 (Risk Spikes & Technical Proof) produces throwaway spike code only.
No UI surfaces are shipped. The spike Avalonia test harnesses (Spikes 3 and 4)
are developer tools, not user-facing interfaces, and require no icons.

No new icons are introduced in this phase. No owner icon-procurement request
is raised.

The icon system is instantiated with the first procurement request to the owner
in Phase 03.
