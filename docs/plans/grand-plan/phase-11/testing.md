## 2. Test corpus for semantic tests

Because real Ollama embeddings cannot run in CI without a running Ollama
instance, the test corpus uses **pre-computed deterministic mock vectors**:

- A fixture of 2,000 books × 200 chunks × 768-dimension float vectors is
  generated by a seeded PRNG and stored as a binary fixture file at
  `tests/Fixtures/embedding-corpus-2k.bin`.
- The mock `IOllamaEmbeddingProvider` for unit/integration tests returns
  vectors from this fixture deterministically keyed by `chunkId`.
- The semantic smoke test (P11-WP8-T6) requires a real local Ollama instance
  and is marked `[Explicit]` — run manually or on a dedicated Ollama-equipped
  runner.

## 8. Determinism test (FR-SEARCH-005)

`HybridRanking_DeterministicOrder` is the most important correctness gate for
FR-SEARCH-005:

1. Seed corpus: 2,000 books with fixed metadata, ratings, statuses, last-opened
   dates, and pre-computed mock embedding vectors.
2. Fixed weight vector: `{0.35, 0.10, 0.10, 0.10, 0.35}`.
3. Generate 100 queries at random from a fixed seed.
4. Run each query → capture `result[0..19].BookId` list.
5. Run all 100 queries again from the same seed → capture second lists.
6. Assert: for all 100 queries, first list = second list (element-wise).

Failure indicates either floating-point non-determinism or an unguarded
dictionary enumeration order. Fix: ensure `OrderBy(x => x.HybridScore)
.ThenBy(x => x.BookId)` is always the final sort step.

## 9. Manual test checklist

- [ ] Type a natural-language query with no title/author keywords; confirm
      semantically relevant books appear (requires local Ollama running with
      configured model).
- [ ] Observe match-location badges on results; hover over badge; confirm
      tooltip explains the match location.
- [ ] Disable Ollama (stop service); type query; confirm results still appear
      (exact search fallback); confirm "Semantic search unavailable" indicator
      visible.
- [ ] Open Index Manager; click "Erase embeddings"; confirm 3-second
      countdown on confirm button; confirm all embeddings removed; confirm
      embedding-generation pipeline restarts.
- [ ] Under VoiceOver (macOS): focus a search result with match-location badges;
      confirm each badge announced (e.g. "Semantic match", "In title").
- [ ] Change UI to French; confirm all semantic search labels, badge tooltips,
      and erasure confirmation text are in French.
