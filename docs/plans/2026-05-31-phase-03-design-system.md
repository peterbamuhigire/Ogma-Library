# Phase 03 Design System Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Scaffold the Phase 03 design system for Ogma Library — design tokens, IconCatalog,
34 placeholder SVG icons, import script, skeleton wiring, screenshot regeneration — keeping
`dotnet build`/`dotnet test`/`dotnet format` green throughout.

**Architecture:** Design tokens live in `Themes/Tokens.axaml` (a ResourceDictionary with
`ThemeDictionaries` for Light/Dark), merged into `App.axaml`. The `IconCatalog` is a plain
static C# registry (no source generators for this pass) that maps each of the 34 `icon_key`
strings to an `avares://` SVG path and an `ILocalizationService` label key. The 34 placeholder
SVGs are generated by a PowerShell script and bundled as `AvaloniaResource`. `Avalonia.Svg.Skia`
renders them via `<SvgImage>` in XAML. The skeleton `MainWindow.axaml` is updated to show tokens
and 2–3 live icons.

**Tech Stack:** .NET 10 LTS, Avalonia 11.3.17, Avalonia.Svg.Skia (NuGet), PowerShell 5.1+,
xUnit + Avalonia.Headless.XUnit (existing UI tests), InMemoryLocalizationService (extended).

```csharp
/// <summary>
/// A resolved icon: the avares:// path for use as an SVG image source and the

/// </summary>

public sealed record IconEntry(string AvaresPath, string AccessibleLabel);

/// </summary>
public static class IconCatalog

            ["ic_lib_folder_open"] = "library/ic_lib_folder_open.svg",
            ["ic_lib_health"] = "library/ic_lib_health.svg",

            ["ic_cat_view_grid"] = "catalogue/ic_cat_view_grid.svg",
            ["ic_cat_view_list"] = "catalogue/ic_cat_view_list.svg",

            ["ic_cat_shelf"] = "catalogue/ic_cat_shelf.svg",
            ["ic_cat_shelf_new"] = "catalogue/ic_cat_shelf_new.svg",
            ["ic_cat_filter"] = "catalogue/ic_cat_filter.svg",
            ["ic_cat_sort"] = "catalogue/ic_cat_sort.svg",

            ["ic_read_open"] = "reader/ic_read_open.svg",

            ["ic_read_zoom_out"] = "reader/ic_read_zoom_out.svg",
            ["ic_read_fullscreen"] = "reader/ic_read_fullscreen.svg",

            // Category: search
            ["ic_search_metadata"] = "search/ic_search_metadata.svg",
            ["ic_search_fulltext"] = "search/ic_search_fulltext.svg",

            // Category: ai
            ["ic_ai_advisor"] = "ai/ic_ai_advisor.svg",
            ["ic_ai_privacy"] = "ai/ic_ai_privacy.svg",
            ["ic_ai_disable"] = "ai/ic_ai_disable.svg",

            // Category: settings
            ["ic_set_appearance"] = "settings/ic_set_appearance.svg",
            ["ic_set_language"] = "settings/ic_set_language.svg",
            ["ic_set_updates"] = "settings/ic_set_updates.svg",
            ["ic_set_about"] = "settings/ic_set_about.svg",

            // Category: status
            ["ic_status_available"] = "status/ic_status_available.svg",
            ["ic_status_unavailable"] = "status/ic_status_unavailable.svg",
            ["ic_status_loading"] = "status/ic_status_loading.svg",
        };

    /// <summary>
    /// Returns the full <c>avares://</c> path for the given icon key, or <c>null</c> if the
    /// key is not registered.
    /// </summary>
    /// <param name="key">The icon key (e.g. <c>"ic_app_logo"</c>).</param>
    /// <returns>The <c>avares://OgmaLibrary.App/Assets/icons/…</c> URI string.</returns>
    public static string? GetAvaresPath(string key)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(key);
        return AssetPaths.TryGetValue(key, out string? rel) ? AssemblyPrefix + rel : null;
    }

    /// <summary>
    /// Resolves an icon to its avares:// path and localized accessible label.
    /// Returns <c>null</c> if the key is not registered.
    /// </summary>
    /// <param name="key">The icon key (e.g. <c>"ic_settings"</c>).</param>
    /// <param name="localization">The active localization service.</param>
    /// <returns>
    /// An <see cref="IconEntry"/> with the asset path and accessible label, or <c>null</c>.
    /// </returns>
    public static IconEntry? Resolve(string key, ILocalizationService localization)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(key);
        ArgumentNullException.ThrowIfNull(localization);

        if (!AssetPaths.TryGetValue(key, out string? rel))
        {
            return null;
        }

        string path = AssemblyPrefix + rel;
        string labelKey = $"Icon.{key}.Label";
        string label = localization[labelKey];
        return new IconEntry(path, label);
    }

    /// <summary>
    /// Returns all 34 registered icon keys.
    /// </summary>
    public static IEnumerable<string> AllKeys => AssetPaths.Keys;
}
```

```powershell
# ── Helper: derive 2-3 letter initials from a key like ic_lib_folder_open ─────
function Get-Initials {
    param([string]$Key)
    # Strip 'ic_' prefix, split on '_', take first letters of up to 3 parts
    $parts = $Key -replace '^ic_', '' -split '_'
    $letters = $parts | ForEach-Object { $_.Substring(0, [Math]::Min(1, $_.Length)).ToUpper() }
    return ($letters | Select-Object -First 3) -join ''
}

        font-size="16"
        font-weight="bold"
        fill="white"
        text-anchor="middle"
        dominant-baseline="central">$Initials</text>
</svg>
"@
    return $svg.TrimStart()
}

    # Write as UTF-8 without BOM (Avalonia SVG loader expects UTF-8)

    Write-Host "  OK    $($icon.Category)/$($icon.Key).svg  [$($icon.Family) $color  $initials]" -ForegroundColor Green
    $generated++
}

Write-Host ""
Write-Host "Phase 03 placeholder icons: $generated generated, $skipped skipped (already real)." -ForegroundColor Cyan
```

```powershell
    'ic_cat_view_shelf3d'   = 'catalogue'
    'ic_cat_view_directory' = 'catalogue'

    'ic_cat_shelf_new'      = 'catalogue'

    'ic_read_open'          = 'reader'
    'ic_read_bookmark'      = 'reader'
    'ic_read_zoom_in'       = 'reader'
    'ic_read_zoom_out'      = 'reader'
    'ic_read_fullscreen'    = 'reader'
    'ic_search_metadata'    = 'search'
    'ic_search_fulltext'    = 'search'
    'ic_ai_advisor'         = 'ai'
    'ic_ai_privacy'         = 'ai'
    'ic_ai_disable'         = 'ai'
    'ic_set_appearance'     = 'settings'
    'ic_set_language'       = 'settings'
    'ic_set_updates'        = 'settings'
    'ic_set_about'          = 'settings'

foreach ($key in $IconCategories.Keys) {
    $srcFile = Join-Path $SourceDir "$key.svg"
    if (-not (Test-Path $srcFile)) {
        Write-Host "  MISS  $key  (not in SourceDir — skipped)" -ForegroundColor DarkYellow
        $notFound++
        continue
    }

    $category = $IconCategories[$key]
    $destDir  = Join-Path $AssetsRoot $category
    $destFile = Join-Path $destDir "$key.svg"

    if (-not (Test-Path $destDir)) {
        $null = New-Item -ItemType Directory -Path $destDir -Force
    }

    Write-Host "  COPY  $category/$key.svg" -ForegroundColor Green

        $missing++
    } elseif ((Get-Item $file).Length -gt 1024) {

        $real++
    } else {
        Write-Host "  🟨 placeholder  $category/$key.svg" -ForegroundColor Yellow
        $placeholder++
    }
}

Write-Host ""
Write-Host "Summary: $real real ✅  |  $placeholder placeholder 🟨  |  $missing missing ⬜" -ForegroundColor Cyan
Write-Host "Imported this run: $imported  |  Not in SourceDir: $notFound"
Write-Host ""
Write-Host "TODO (post-Phase 03): generate PNG @1x/@2x/@3x variants from SVG masters." -ForegroundColor DarkGray
Write-Host "Run 'dotnet build' after importing to pick up the new AvaloniaResource assets."
```

## Known pitfalls

1. **`Avalonia.Svg.Skia` namespace in XAML:** The `<svg:SvgImage>` control needs
   `xmlns:svg="using:Avalonia.Svg.Skia"`. If the namespace resolves to a type that doesn't
   exist, confirm the NuGet package version matches `11.3.17`.

2. **DynamicResource in ThemeDictionaries:** Token brushes in `ThemeDictionaries` must be
   referenced with `DynamicResource` (not `StaticResource`) in controls; `StaticResource`
   does not cross `ThemeDictionaries` boundaries.

3. **AvaloniaResource for `.axaml` files:** Avalonia XAML resource dictionaries included via
   `<ResourceInclude Source="avares://..."/>` must themselves be bundled as `AvaloniaResource`
   in the csproj. The `<AvaloniaResource Include="Themes\Tokens.axaml" />` line in Task 9
   handles this.

4. **`CornerRadius` in XAML resource:** `<CornerRadius x:Key="...">N</CornerRadius>` is the
   correct form. If the XAML parser complains, try the full form
   `<CornerRadius x:Key="...">N,N,N,N</CornerRadius>`.

5. **SVG path attribute:** `Avalonia.Svg.Skia`'s `SvgImage` uses `Path` (not `Source`) for
   the asset URI. Confirm with the installed package version's API.

6. **compiled bindings and `AutomationProperties.Name`:** `AutomationProperties.Name` with a
   binding requires the `x:DataType` to be set, which it is on `MainWindow`. If the compiler
   complains about binding type, add `x:CompileBindings="False"` only on that attribute as
   a last resort.
