Return strict JSON only. Use this shape:
{
  "goal": "the user's goal",
  "steps": [
    {
      "book_id": "local-book-id",
      "rationale": "Why this book belongs at this point in the sequence.",
      "difficulty": "Introductory|Foundational|Intermediate|Advanced|Expert",
      "estimated_reading_days": 7
    }
  ],
  "checkpoints": [
    { "after_step": 0, "description": "A short reflective checkpoint." }
  ]
}

Rules:
- Never invent a book_id. Use only ids present in books.*.id.
- Return between 1 and plan.max_books steps.
- Use difficulty labels exactly as listed in the schema.
- Make rationales concrete and grounded in the supplied metadata.
- Checkpoints may be empty for short plans, but the checkpoints property must be present.
